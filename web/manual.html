Chapter 1

Start in one minute

sUML draws UML and architecture diagrams on your own PC. Nothing is ever uploaded.

  1. Download sUML-v1.1-windows.zip from GitHub releases.
  2. Right-click it and choose Extract All. Don’t run it from inside the zip.
  3. Put the folder in Documents, then double-click sUML.exe.
  4. If Windows shows “Windows protected your PC”, choose More info, then Run anyway.

Where your work lives

  • Your files: wherever you save them (.suml.json)
  • Open tabs: autosaved, so they survive a restart
  • Settings: sUML.config.json next to the exe

What you can draw

  • Flowcharts and activity diagrams
  • Software and hardware architecture
  • Use case, dataflow, class diagrams
  • Swimlanes

Chapter 3

Drawing

Ten tools cover almost everything you draw.

Add a shape

What

Put a box, diamond, actor, database… on the canvas.

How

  1. Click it in the Shapes panel
  2. …or drag it onto the canvas
  3. Right-click it → add to Favorites

Connect two shapes

What

An arrow that sticks to both shapes when you move them.

How

  1. Hover a shape: 4 dots appear
  2. Drag a dot onto another shape
  3. Drop on a dot to pick the exact side

Draw arrow

What

Draw a line anywhere, like a pen.

How

  1. Pick Draw arrow (Shapes panel)
  2. Drag on the canvas
  3. Start on a shape: it snaps on

Free arrow

What

A loose arrow, or a quick link between two boxes.

How

  1. Click Free arrow
  2. 2 boxes selected? they get linked

Edit text

What

Change the words on a shape or line.

How

  1. Double-click, or select + F2
  2. Ctrl+Enter = done, Esc = cancel

Move or detach a line

What

Move a line; keep or break its links.

How

  1. Drag it: ends slide along their box
  2. Shift+drag: the ends let go
  3. Drag an end dot to re-attach it

Joints (bends)

What

Bends you place yourself.

How

  1. Ctrl+drag on a line adds one
  2. Drag the small square to move it
  3. Double-click it to remove it

Resize

What

Make a shape bigger or smaller.

How

  1. Drag a corner or side handle
  2. Hold Ctrl: grows around the centre

Line looks

What

Size, style, ends, colour and label.

How

  1. Select the line → right panel
  2. Thin · Medium · Thick
  3. Solid · Dashed · Dotted

Undo and redo

What

Take back any change, one at a time.

How

  1. Ctrl+Z = undo
  2. Ctrl+Y = redo

Chapter 4

Arranging

Align, order and route from the Align button in the top bar.

Align

What

Line selected boxes up on one edge or centre.

How

  1. Select 2 or more boxes
  2. Align → Left, Center, Right
  3. …or Top, Mid, Bottom

Distribute

What

Make the gaps between boxes equal.

How

  1. Select 3 or more boxes
  2. Align → Distribute horizontally
  3. …or Distribute vertically

Auto-order

What

Lay out one whole flow in a direction you pick.

How

  1. Select one flow (boxes + arrows)
  2. Align → click an arrow around 1st
  3. 1st stays; the rest follow it

Auto-route

What

A tidy right-angle path around shapes; both ends stay put.

How

  1. Select lines (or their boxes)
  2. Align → Auto-route

Straight

What

A perfectly straight line between boxes that face each other.

How

  1. Select lines
  2. Align → Straight

Layers

What

Choose what sits on top. Shapes 0–1000, pen ink 0–50.

How

  1. Right panel → Layer number
  2. Right-click → Move layer +1 / −1
  3. Layers panel: click to select all

Auto-order and Auto-route need Smart on. Shift+drag a group or swimlane to move only the container.

Chapter 5

Smart and settings

Smart, in the top bar, switches every helper on or off at once. With it off, sUML is a plain drawing tool.

Place next

What

New shape lands beside the selected one, lined up and connected.

How

  1. Select a box
  2. Click a shape in the Shapes panel

Fade unrelated

What

Everything not linked to the selected box fades out.

How

  1. Select one box
  2. Turn off in Settings if you like

Clean routing

What

Right-angle lines go around shapes and avoid lying on other lines.

How

  1. Works by itself
  2. Tune it in Settings → Smart routing

Parallel lines

What

Lines that would overlap fan out side by side and never cross.

How

  1. Works by itself on elbow lines

Auto-connect

What

A loose line end connects when a shape touches it.

How

  1. Drag a shape onto the loose end

Auto layer

What

A shape dropped on another moves up a layer; off again, back down.

How

  1. Settings → Auto increment layer
  2. Pick the Increment number

Settings (the gear in the top bar)

  • Default text: sample text on new shapes, or start empty
  • Fade unrelated objects: on or off
  • Auto increment layer with an increment number
  • Avoid object overlap: 0–10 extra bends
  • Avoid line overlap: 0–10 extra bends
  • Thicker overlapped lines: sizes added together

Chapter 6

Marks, pen and comments

Mark, number, sketch on and review your diagram.

Colours

What

One palette for every colour button, with your 13 recent colours.

How

  1. Click a colour button
  2. Pick a swatch, or type #0a7

Important mark

What

Lightning, !, check, cross, or a red / green / blue dot on a shape.

How

  1. Right-click a shape
  2. Pick a mark (∅ removes it)

Flow numbers

What

Number shapes 1, 2, 3… in the order their arrows run (max 99).

How

  1. Select the shapes, right-click
  2. Count selected flow order
  3. Pick the corner for the number

Pen

What

Draw freely by hand on its own ink layer, above the diagram.

How

  1. Click Pen, or press P
  2. Choose colour, size, highlighter
  3. Esc to stop

Comments

What

Review notes with text and images pinned to an area.

How

  1. Click Comment, then Add comment
  2. Drag over the area
  3. Type, paste screenshots (Ctrl+V)
  4. Mark as done when fixed

Chapter 7

Code panel

The whole diagram as text. Type a line to add a shape, delete a line to remove it, then apply.

  1. Click Code at the bottom right, or press Ctrl+`.
  2. Edit the text. Each shape and each line is one row.
  3. Press Apply or Ctrl+Enter. Ctrl+Z undoes it.
n1: terminator "Start" @240,30 120x44
n2: diamond "In stock?" fill=#fef9c3
n3: rect "Ship order"
n1 -> n2
n2 -> n3 "yes" route=ortho width=thick

A shape row

id: type "text" @x,y WxH

  • Leave out @x,y and it’s placed for you
  • Settings: fill, stroke, color, layer, mark, flow…

A line row

from ARROW to "label"

  • Arrows: -> --> ..> -- -|> ..|> <-> *-- o--
  • Settings: route=ortho, width=thick, color

Mistakes are safe. Errors are listed with their line number and nothing changes until they’re fixed.

How

SVG or PNG for slides and documents. Comments are left out.

How

  1. Click SVG or PNG (top bar)
  2. Theme menu: white or theme colours

Tabs

What

Several diagrams open at once, autosaved.

How

  1. + opens a new tab
  2. A dot means not saved yet

Themes

What

Basic, Dark, Starry Night, Forest, Burning.

How

  1. Click Theme
  2. Pick one; your colours stay

Shortcut slots

What

Add favourite shapes from the keyboard.

How

  1. Click Shortcuts (top right)

  3. Ctrl or Alt + 1–0 / Q–T

Settings

What

Default text, auto layer, fading and routing options.

How

  1. Click ⚙ in the top bar
  2. Saved next to sUML.exe

Chapter 10

Quick fixes

  • “Windows protected your PC”Choose More info, then Run anyway.
  • The app won’t startInstall the Microsoft Edge WebView2 Runtime. It’s built into Windows 10 and 11.
  • Settings don’t stickMove the sUML folder out of Program Files, for example to Documents.
  • Auto features do nothingTurn Smart on in the top bar.
  • Auto-order refusesSelect only one flow: one start, one end, all connected.
  • Pasting a screenshot does nothingSwitch to comment mode first.
  • Code panel shows errorsFix the listed line numbers. Nothing changes until they’re fixed.
  • Is anything uploaded?No. sUML works fully offline.
